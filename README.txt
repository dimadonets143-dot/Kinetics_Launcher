KINETICS LAUNCHER 2.2  —  лаунчер Minecraft на Python
=====================================================

ФАЙЛЫ
  start.bat      запустить лаунчер (нужен Python 3.9+, галочка "Add to PATH")
  build_exe.bat  собрать Kinetics.exe (потом Python не нужен)
  Если лаунчер не открылся — смотри data\crash.log

ГЛАВНАЯ
  Большая кнопка "Продолжить" запускает последнюю версию.
  Ниже — список недавних и скачанных версий, у каждой своя кнопка "Играть".
  Ник меняется прямо в шапке. Журнал игры — кнопка "Журнал".

РАЗДЕЛЫ
  Версии        релизы / снапшоты / беты / альфы / установленные, Vanilla или Fabric
  Магазин       Modrinth: набор оптимизации, моды, шейдеры, ресурспаки
  Профиль       профили, ник, окно, сервер, команды, переменные окружения
  Оптимизация   авто-подбор под ПК, пресеты, память, Java, JVM-флаги
  Графика       настройки игры -> options.txt
  Внешний вид   8 тем (в т.ч. светлые), акцентный цвет, шрифт,
                фон шапки (градиент / частицы / своя картинка), анимации

ШЕСТЕРЁНКА (справа сверху)
  Графический API: OpenGL / Vulkan через Mesa Zink / программный.
  Видеокарта Windows для Java: авто / встроенная / дискретная.
  Быстрый старт (кэш классов Java 19+), пауза анимаций во время игры,
  ярлык на рабочий стол и в меню Пуск (с иконкой).
  Для Zink/программного режима нужна папка Mesa с opengl32.dll
  (кнопка "Скачать Mesa" открывает страницу сборок).

БЫСТРЫЙ ЗАПУСК
  Лаунчер запоминает проверенные версии, Java и Fabric и не проверяет
  всё заново при каждом старте. "Скачать / проверить файлы" в разделе
  Версии принудительно перепроверяет всё.

ВАЖНО
  * Файлы игры качаются с официальных серверов Mojang.
  * Оффлайн-режим: свободный ник; серверы с online-mode=true и скины
    требуют купленного аккаунта.
  * Для шейдеров нужны Fabric + Iris + Sodium (кнопка в магазине ставит их).
  * Альфы и беты запускаются «как есть», нужна Java 8.
  * Forge/NeoForge пока не поддерживаются.
  * Все данные лежат в папке data рядом с лаунчером.
